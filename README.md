# 🍕 比薩拼圖大冒險（Pizza, Pizza!）

專為 **3–7 歲幼兒園小朋友與親子共玩** 設計的互動網頁版桌遊＋**精準 6.3 × 8.8 cm 實體列印卡牌**，靈感源自經典兒童桌遊《Pizza, Pizza!》。

## 🌐 線上連結（GitHub Pages）
- **🎮 互動網頁版遊戲／雙轉盤**：https://sunking2121-hub.github.io/pizza-pizza-game/
- **🃏 6.3 × 8.8 cm 實體卡牌列印版（共 36 張）**：https://sunking2121-hub.github.io/pizza-pizza-game/print-cards.html
- **📖 實體卡牌遊戲使用說明書（A4 雙頁可列印）**：https://sunking2121-hub.github.io/pizza-pizza-game/manual.html

## 遊戲特色
- **雙轉盤（顏色＋形狀）**：學習辨識紅、黃、綠、藍四種顏色與圓形、三角形、正方形、星形四種形狀。
- **兩種適齡難度**：
  - 🌈 **基礎模式（3–5 歲）**：顏色**或**形狀符合其中一個就能選。
  - ⭐ **挑戰模式（5–7 歲）**：顏色**而且**形狀兩個都要符合。
- **翻開驚喜與噁心配料垃圾桶**：翻到美味配料放進自己的披薩盤；翻到毛毛蟲、臭襪子、小蜘蛛、魚骨頭等「噁心配料」時，點擊丟進垃圾桶哈哈大笑！
- **虛實整合**：可直接列印 6.3 × 8.8 cm 標準尺寸實體卡牌（支援 A4 雙面鏡像對齊與 5 cm 校準尺），搭配手機／平板網頁雙轉盤一起玩！
