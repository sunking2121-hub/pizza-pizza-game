# 🍕 比薩拼圖大冒險（Pizza, Pizza!）

專為 **3–7 歲幼兒園小朋友與親子共玩** 設計的互動網頁版桌遊，靈感源自經典兒童桌遊《Pizza, Pizza!》。

## 遊戲特色
- **雙轉盤（顏色＋形狀）**：學習辨識紅、黃、綠、藍四種顏色與圓形、三角形、正方形、星形四種形狀。
- **兩種適齡難度**：
  - 🌈 **基礎模式（3–5 歲）**：顏色**或**形狀符合其中一個就能選。
  - ⭐ **挑戰模式（5–7 歲）**：顏色**而且**形狀兩個都要符合。
- **翻開驚喜與噁心配料垃圾桶**：翻到美味配料放進自己的披薩盤；翻到毛毛蟲、臭襪子、小蜘蛛、魚骨頭等「噁心配料」時，點擊丟進垃圾桶哈哈大笑！
- **支援 1–4 人同樂與電腦陪玩**：可切換動物頭像、自訂名字，也可開啟「🤖 小熊電腦」一起玩。
- **中文語音小幫手＆可愛音效**：免識字也能聽語音引導遊玩（使用 Web Speech API 與 Web Audio API，純前端免後端）。

## 線上遊玩 / 本地開啟
純靜態 HTML / CSS / JavaScript 製作，直接雙擊開啟 `index.html` 或部署至 GitHub Pages 即可遊玩！
